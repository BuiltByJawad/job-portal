# Job Portal - Role 3 (Recruiter)

## Run Locally (XAMPP)
1. Copy this project into your htdocs path.
2. Import `sql/schema.sql` in phpMyAdmin.
3. Run `sql/migrations_step4.sql`.
4. (Optional) import `sql/seed_role3_demo.sql` for demo data.
5. Update DB config in `app/config/config.php` if needed.
6. Visit `/project/public/index.php`.

## Implemented Milestones
- Step 1: MVC scaffold + recruiter auth + shared schema
- Step 2: recruiter clients + recruiter job posting + job filters
- Step 3: AJAX seeker search + outreach messaging
- Step 4: applications pipeline + placement tracking + analytics/client report
- Step 5: complaints flow + validation hardening + demo seed SQL
