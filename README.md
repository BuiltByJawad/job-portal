# Job Portal - Role 3 (Recruiter)

## Run Locally (XAMPP)
1. Copy this project into your htdocs path.
2. Create database and tables by running `sql/schema.sql` in phpMyAdmin.
3. Update DB config in `app/config/config.php` if needed.
4. Visit `/project/public/index.php`.
